# Software Development Company Website

A modern, responsive one-page website built with HTML, CSS, and JavaScript, inspired by GoMilestone.com.

## 🚀 Features

- **Fully Responsive Design** - Works seamlessly on desktop, tablet, and mobile devices
- **Modern UI/UX** - Beautiful gradients, smooth animations, and hover effects
- **Interactive Elements** - Portfolio tabs, mobile menu, smooth scrolling navigation
- **Service Showcase** - 8 comprehensive service offerings
- **Portfolio Section** - Tabbed interface for website and mobile projects
- **Technology Stack Display** - Organized by categories (Frontend, Backend, etc.)
- **Pricing Models** - Three flexible engagement options
- **Contact Section** - Multiple contact methods (phone, WhatsApp, email)
- **SEO Friendly** - Semantic HTML structure

## 🚀 Getting Started

1. **Open the website:**
   - Simply open `index.html` in your web browser
   - Or use a local server for better performance

2. **Using a Local Server (Recommended):**
   ```bash
   # If you have Python installed:
   python -m http.server 8000
   
   # If you have Node.js installed:
   npx serve
   
   # Then open: http://localhost:8000
   ```

3. **Add Your Images:**
   - Place all required images in the `assets/images/` folder
   - Update image filenames in `index.html` if needed

## 🎯 Customization

### Update Company Information:
- Edit `index.html` to change company name, services, and content
- Update contact information in the Contact section
- Modify social media links in the footer

### Change Colors:
- Open `styles.css`
- Modify CSS variables in the `:root` section:
  ```css
  :root {
      --primary-color: #2563eb;
      --secondary-color: #7c3aed;
      --accent-color: #f59e0b;
      /* ... more variables */
  }
  ```

### Add/Remove Sections:
- Edit `index.html` to add or remove sections
- Update navigation links accordingly
- Adjust spacing in `styles.css` if needed
